## 2. AI와 LLM의 기초

### AI, 머신러닝, 딥러닝, 생성형 AI

AI는 인간의 지능적인 작업을 컴퓨터가 수행하도록 하는 넓은 분야다.

머신러닝은 데이터로부터 패턴을 학습하는 AI의 한 분야이며, 딥러닝은 여러 층의 신경망을 활용하는 머신러닝의 한 분야다.

생성형 AI는 학습한 패턴을 바탕으로 새로운 텍스트, 이미지, 코드 등의 결과물을 생성하는 AI다.

### LLM이란?

LLM(Large Language Model)은 대규모 언어 데이터를 학습한 언어 모델이다.

LLM을 활용할 때 알아야 할 개념도 함께 공부했다.

- **Token:** 모델이 텍스트를 처리하는 기본 단위
- **Context Window:** 모델이 한 번에 참고할 수 있는 정보의 범위
- **Hallucination:** AI가 사실과 다르거나 근거가 부족한 내용을 그럴듯하게 생성하는 현상

AI의 답변은 항상 정확한 사실이라고 생각해서는 안 된다. 중요한 정보는 별도로 확인하는 과정이 필요하다.

## 3. 프롬프트 구성 방법

좋은 결과를 얻기 위해 프롬프트에 포함할 수 있는 다섯 가지 요소를 공부했다.

| 요소 | 의미 |
|---|---|
| Task | AI에게 무엇을 시킬 것인가 |
| Context | 어떤 배경 정보를 제공할 것인가 |
| Constraints | 어떤 조건이나 제한을 둘 것인가 |
| Output Format | 결과를 어떤 형태로 받을 것인가 |
| Success Criteria | 어떤 결과를 좋은 결과로 판단할 것인가 |

질문을 구체적으로 작성하면 AI가 요청의 의도를 이해하고 원하는 형태로 답변하는 데 도움이 된다.

## 5. 오늘의 회고

오늘은 AI를 활용하는 데 있어 질문을 작성하는 방식 자체가 중요하다는 점을 공부했다.

단순히 질문을 입력하는 것보다 원하는 작업과 배경, 조건, 결과 형태를 명확히 전달하는 것이 중요하다.

다만 프롬프트를 구체적으로 작성한다고 해서 항상 정확한 답변이 나오는 것은 아니다. AI가 제공한 정보를 검토하고 판단하는 과정 역시 필요하다.

앞으로는 AI를 단순한 정보 검색 도구로 사용하는 것을 넘어, 문제 해결과 개발 과정에서 효과적으로 활용하는 방법을 익히고 싶다.
